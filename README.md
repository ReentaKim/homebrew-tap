# ReentaKim/homebrew-tap

```sh
brew install --cask reentakim/tap/sagebar
brew install --cask reentakim/tap/modoit
brew install --cask reentakim/tap/kkok
```

| Cask | 설명 |
|---|---|
| [sagebar](https://github.com/ReentaKim/SageBar) | 네 현자의 아침 조언 메뉴바 앱 |
| [modoit](https://github.com/ReentaKim/Modoit) | 쓴 메모를 그대로 바탕화면에 붙여 두는 Mac 메모 앱 |
| [kkok](https://github.com/ReentaKim/Kkok) | 찍고, 콕 짚고, 끌어서 붙이는 화면 캡처·주석 앱 |
